# Artifact Gallery

This gallery is designed for fast visual scanning. It does not mirror the entire `figures/` folder one-to-one. Instead, it pulls forward the artifacts that best explain the system:

- core training curves
- PPO loss traces
- curriculum progression
- ablation comparisons with mean and standard deviation bands

The generated [artifact gallery](/generated/artifact-gallery) page is assembled from the current contents of `figures/` plus the figure metadata table in `figures/figure_metadata.csv`. That means the image selection and captions are grounded in files already present in the repo rather than hand-authored marketing copy.
